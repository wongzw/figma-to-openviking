# Names and paths

```
<destination>/<Page>/<Section>/<NN>_<frame name>_<node-id>.png
<destination>/<Page>/manifest.md
```

Example:

```
viking://resources/ui-design-reference/Checkout/
  00-Before/01_购物车_12-345.png
  01-After-V2/01_购物车｜默认态_12-401.png
  01-After-V2/02_购物车｜库存不足_12-402.png
  manifest.md
```

## Rules

- `NN` is reading order, so folder listings show the flow. If the Figma name already starts with a number (`07 支付成功`), use that number; don't add another. Otherwise number frames in canvas order within their section.
- Node ID: `12:345` → `12-345`. It keeps names unique and links back to Figma.
- `plan_names.py` cleans names: spaces and `·` → `-`; removes `/ \ : * ? " < > |` and control characters; cuts to 60 characters; replaces emails, phone numbers, URLs, keys, tokens and long ID-like numbers with `x`. Keep Chinese and `｜`.
- When renaming `TODO 命名` frames by hand, describe the screen (`空状态-无订单`). Never use people's names, emails, phone numbers, order or account numbers, or keys from the screen.
- Frames directly on the page (no section) go straight into the page folder.
- One Figma page = one page folder.

## Re-imports

| Situation | Do |
|---|---|
| User asked to replace the page | `upload.sh … --replace` |
| Same file content (md5) remotely | skip |
| Content changed, no replace asked | upload as `<name>_v2_<node-id>.png`, note old → new in the manifest |
| New frames only | `ov add-resource <file> --to <exact uri> --wait` per file |

Never delete remote files the user didn't ask to remove.

## manifest.md

Generated by `plan_names.py`. It keeps the source link, source node, frame count, selection rule, and one row per file (order, file, Figma name, section, node link, size, scale, note). Names in it are escaped and scrubbed the same way as file names. Agents read it first, so fill every `TODO` before upload.
